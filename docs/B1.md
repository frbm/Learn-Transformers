## Results

**Tests:** 8 pass. In the given test, the μP logit-change slope is |s| < 0.2 and the SP slope is > 0.3.

| SP, step 2 | −0.01 | 1.01 | 1.39 | 1.52 | 1.55 | 0.80 |
| SP, step 10 | −0.06 | 1.50 | 1.33 | 1.44 | 1.62 | 0.73 |
| μP, step 2 | 0.00 | −0.08 | −0.11 | −0.14 | −0.15 | −0.14 |
| μP, step 10 | −0.01 | −0.08 | −0.03 | −0.05 | −0.03 | −0.01 |

μP is flat (|slope| ≤ 0.15). In SP the blocks fan out first, with a slope of about 1.5. The hidden matrices get the global lr instead of lr/m, so their spectral update is m times too large (Proposition 3), and the error compounds through the depth. The logits fan out less (0.7–0.8) because the readout is the last matrix, but its update is too large by a factor n, which is the readout row of §2. The embedding row is the same in both parametrisations, so its slope is 0 in both.

**Task 4 (smoke run only:** widths 128 and 256, lr 2⁻¹⁰ and 2⁻⁷, 30 steps). The SP optimum moves from 2⁻⁷ at width 128 to 2⁻¹⁰ at width 256. The μP optimum stays at 2⁻⁷. Thirty steps prove only that the pipeline and the resume work. Run the full 54-run sweep before you draw conclusions.

## Answers

**Task 1: my table, derived from Propositions 2–3 before reading.** The condition is ‖W‖₂ and ‖ΔW‖₂ = Θ(√(fan-out/fan-in)). Adam updates have ‖ΔW‖₂ ≈ η√(fan-out·fan-in), so η ∝ 1/fan-in. The init std is σ = (1/√fan-in)·min(1, √(fan-out/fan-in)). Embedding (fan-in K, constant): σ₀ and η₀. Hidden: σ₀/√m and η₀/m. Readout (fan-out K): σ₀/m and η₀/m. Vectors: 1 and η₀. This is the table in `lm/model/mup.py`. The readout init is zero in μP, the limit case of σ₀/m, so the step-0 loss is exactly log K.

- **Tied or untied.** Untied. The embedding row wants Θ(1) entries and η₀, and the readout row wants 1/m for both. One tensor cannot follow two rows. `init_weights` unties the readout.
- **Weight decay.** I hold η·λ fixed per kind (`weight_decay / lr_mult`). AdamW decays by η·λ per step, so this keeps the decay time scale independent of width. Vectors get no decay.

**§3 exercise (GQA).** (i) With n_kv ∝ n (fixed group size, as in `make_model`), W_K and W_V are square-like hidden matrices: σ₀/√m and η₀/m. (ii) With n_kv fixed and n_q ∝ n, the fan-out n_kv·d_h is constant and the fan-in is n. The condition then gives σ = √(fan-out)/fan-in ∝ 1/n, which is readout-like and not 1/√n, and η ∝ 1/fan-in = η₀/m, the same as hidden. So W_K and W_V take the readout init with the hidden learning rate.

**Interview (60 s).** In SP, every matrix gets the same Adam learning rate. Adam updates have entries of size η, so the spectral norm of an update grows like η·√(fan-in·fan-out). For the readout this is n times too large, so the logit updates grow with width. The largest stable learning rate, and with it the optimum, moves down like 1/n. μP sets the learning rate of each matrix to η₀/fan-in, and the readout init to O(1/n). Then each layer moves its output by Θ(1) per step at every width. The training dynamics have a feature-learning limit, so the optimum stops moving with width. Tune at width 128, then train at 2048 with the same η₀.

## Research-engineering tricks

- **A test that must be able to fail.** `test_sp_logit_updates_grow_with_width` checks that the coordinate check detects the bug that μP fixes. A check that passes for both parametrisations measures nothing.
- **Classify every parameter, and assert it.** `param_groups` asserts that the group sizes sum to the parameter count. A silently unclassified tensor is the typical μP bug.
- **Per-group base learning rates.** The `Trainer` stores `base_lr` per group and multiplies it by the schedule. One global value written into every group would erase μP. (A3's loop does that; that is why every later module uses the `Trainer`.)
- **A sweep you can kill.** One JSON line per finished run, keyed by `(param, width, lr, seed)`. On start, skip the keys that are already done. Results never live only in memory.
- **Slopes, not pictures.** The coordinate check prints d log ‖Δh‖ / d log n per layer type. One number per curve is easier to compare, assert and record than a figure.
- **Zero readout at init.** The step-0 loss is then exactly log K at every width: a free sanity check.
